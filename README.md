# Sprint_5 — автотесты для Stellar Burgers

Финальный проект: UI-автотесты на Selenium + pytest для учебного сервиса
[Stellar Burgers](https://qa-stellarburgers.education-services.ru/) — космического фастфуда,
где можно собрать бургер из необычных ингредиентов.

## Что проверяется

| Файл | Функциональность |
|------|------------------|
| `tests/test_registration.py` | Успешная регистрация, ошибка при пароле короче 6 символов |
| `tests/test_login.py` | Вход через «Войти в аккаунт», «Личный кабинет», форму регистрации, форму восстановления пароля |
| `tests/test_personal_account.py` | Переход в личный кабинет; переход в конструктор по «Конструктору» и по логотипу |
| `tests/test_logout.py` | Выход из аккаунта по кнопке «Выход» |
| `tests/test_constructor.py` | Переходы к разделам «Булки», «Соусы», «Начинки» |

## Структура проекта

```
Sprint_5/
├── tests/                  # все тесты (по одному файлу на функциональность)
├── conftest.py             # все фикстуры
├── locators.py             # локаторы с комментариями
├── data.py                 # URL и генераторы email / пароля
├── requirements.txt        # зависимости
├── .gitignore
└── README.md
```

## Генерация данных

В `data.py`:
- `generate_email()` — email вида `имя_фамилия_когорта_XXX@домен`, где `XXX` — три случайные цифры
  (формат `ivan_petrov_99_123@yandex.ru`), чтобы почта была уникальной;
- `generate_password(length=6)` — случайный пароль (минимум 6 символов).

## Запуск

1. Установите Google Chrome (тесты запускаются в нём; драйвер Selenium Manager подтянет сам).
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите все тесты:
   ```
   python -m pytest tests/ -v -s
   ```

Каждый тест автономен: открывает браузер, выполняет проверку и закрывает его (`driver.quit()` в фикстуре).
